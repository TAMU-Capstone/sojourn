# Camera scene source imagery

Source images for the stored camera scenes (`tools/gen_scenes.py` converts
these to raw grayscale in `app/scenes.c`).

| File | Subject | Credit |
|---|---|---|
| `ceres.png` | Dwarf planet 1 Ceres, Occator crater bright spots | NASA/JPL-Caltech/UCLA/MPS/DLR/IDA (Dawn) — public domain |
| `saturn_hexagon.png` | Saturn north polar vortex and rings | NASA/JPL-Caltech/Space Science Institute (Cassini) — public domain |

The survey star field and the Mimas easter-egg scene are generated
procedurally by `gen_scenes.py` rather than imported.

NASA imagery is generally not copyrighted and may be used for educational
purposes; see https://www.nasa.gov/nasa-brand-center/images-and-media/
